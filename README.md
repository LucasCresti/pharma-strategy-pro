# 💊 PharmaStrategy Pro

Sistema inteligente para gestão de validade e otimização de lucro em farmácias.

## 🚀 Funcionalidades
- **Controle de Estoque:** Cadastro com Lote, Laboratório e Quantidade.
- **Classificação:** Separação entre Éticos, Genéricos e Similares.
- **Inteligência Financeira:** Cálculo automático de prejuízo em risco.
- **Sugestão de Ofertas:** Algoritmo que sugere descontos baseados na proximidade do vencimento para salvar o capital.
- **Dashboard Visual:** Gráficos em tempo real para tomada de decisão.

## 🛠️ Tecnologias
- HTML5 / CSS3 (Design Responsivo)
- JavaScript Vanilla (Lógica de Negócio)
- Chart.js (Visualização de Dados)
- LocalStorage (Persistência de dados no navegador)# pharma-strategy-pro
